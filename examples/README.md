# Examples

This directory contains synthetic examples for documentation and tests of public repository structure.

The files do not contain real procurement documents, real winners, personal data, local paths, cookies, tokens, or downloaded EIS URLs.

All example files are authored from scratch. They are not generated from, copied from, transformed from, or sanitized from real downloaded procurement documents or local analysis outputs. They demonstrate public output schemas and decision presentation only.

- `sample_candidate.json`: synthetic input-like candidate card.
- `sample_analysis.json`: synthetic analyzer output-like card with evidence and decision fields.
- `sample_document_classification.csv`: synthetic document classification rows using the production `document_classification.csv` columns.
- `sample_quality_issues.csv`: synthetic data-quality rows using the production `quality_issues.csv` columns.
- `sample_unresolved_fields.csv`: synthetic unresolved-field rows using the production `unresolved_fields.csv` columns.
- `sample_conflicts.csv`: synthetic low-risk conflict row using the production `field_conflicts.csv` columns.
- `sample_summary.md`: synthetic human-readable analysis summary for the same fictional procurement.
