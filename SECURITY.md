# Security Policy

This repository is intended to contain source code, tests, documentation, and synthetic examples only.

## Public Data Rules

- Do not publish cookies, bearer tokens, API keys, passwords, session identifiers, private keys, or browser profiles.
- Do not commit downloaded procurement documents, HTML page snapshots, generated analysis outputs, local XLSX/CSV/JSON datasets, logs, archives, or backups.
- Do not bypass source access restrictions or authentication boundaries.
- Respect request rate limits and use conservative delays when collecting public pages.
- Use only publicly available data and verify the source terms of use before collection.
- Vulnerability reports and issues must not include secrets, live cookies, private URLs, or personal data.

## Project Scope

The analyzer is a rule-based portfolio project. It does not guarantee legal correctness, financial suitability, or a valid decision to participate in a procurement. Any operational use requires independent legal, financial, and technical review.
